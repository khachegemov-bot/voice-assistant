ГОЛОСОВОЙ ПОМОЩНИК — диктовка и перевод лекций. Работает на Windows 10/11.
Подробная инструкция с картинками — файл «Инструкция.html» (откройте двойным щелчком).

ЗАПУСК
  1. Распакуйте архив в любую папку (например, «Документы»). Не запускайте прямо из архива.
  2. Откройте «Голосовой помощник.exe».
     Если Windows скажет «Система Windows защитила ваш компьютер» — нажмите «Подробнее» →
     «Выполнить в любом случае». Это обычное предупреждение для программ без цифровой подписи.
  3. Закрытие окна (✕) не выключает программу — она уходит к часам (значок микрофона).
     Полностью выйти: правый клик по значку у часов → «Выход».
  4. Чтобы программа запускалась сама — в разделе «Настройки» включите «Запускать вместе с Windows».

ДИКТОВКА — Alt+Z
  Нажмите Alt+Z (или большую кнопку с микрофоном на «Главной») и говорите: слова плавно появляются
  в окошке внизу экрана, оно растёт вместе с текстом. Синяя точка дышит в такт голосу — значит,
  вас слышно. Остановить можно и красной кнопкой в самом окошке.
  Ещё раз Alt+Z — текст вставится туда, где стоит курсор (Word, браузер, мессенджер…).
  Пока вы говорите, программа в фоне перепроверяет запись целыми фразами — вставляется уже
  исправленный текст.
  Язык: «Авто» определяет его по голосу — говорите по-русски или по-английски, раскладку
  переключать не нужно. Можно выбрать и вручную (на «Главной»).
  Команды голосом: «новая строка», «новый абзац» (по-английски «new line», «new paragraph»).
  Запинки («э-э-э», «эм») программа убирает сама.
  Словарь (раздел «Настройки»): если программа пишет слово неправильно, добавьте строку
  «как слышится = как писать», например «клоуд* = Claude» (звёздочка — любое окончание).
  История последних 10 диктовок (с поиском) — раздел «История».

ЛЕКЦИИ И ПОДКАСТЫ — Alt+X
  В разделе «Лекции» выберите, откуда слушать:
    • Весь звук — всё, что играет на компьютере.
    • Программа — только одно приложение (Zoom, Teams, браузер…). Остальной звук в запись
      не попадает, поэтому можно параллельно смотреть своё видео в ДРУГОЙ программе.
      «Приглушить её для меня» — лекция почти не слышна вам, но запись не страдает.
    • Ссылка — вставьте ссылку на YouTube / VK Видео / Twitch. Запись обрабатывается быстрее
      реального времени (часовая лекция — примерно за 10–15 минут), прямой эфир — по ходу.
  Alt+X — начать, ещё раз Alt+X — остановить: появится перевод на русский и текст оригинала.
  Всё сохраняется в «Документы → Голосовой помощник → Лекции».

ПЕРЕВОД
  «Онлайн · Google» — лучше качество, нужен интернет (английский текст отправляется в Google).
  «Офлайн» — всё на компьютере, без интернета, перевод чуть более буквальный.
  Распознавание речи всегда работает на компьютере, без интернета.

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
  • Окошко пишет «Микрофон выключен» — включите микрофон (клавиша с перечёркнутым микрофоном
    на ноутбуке или Параметры → Система → Звук → Ввод).
  • «Alt+Z/Alt+X занята другой программой» — закройте другие программы для диктовки.
  • Журнал работы: %LOCALAPPDATA%\Голосовой помощник\log.txt — его можно прислать автору.
